# Smart Dustbin Prototype

## Prototype Overview

The Smart Dustbin prototype is designed to monitor the waste fill level and provide an alert before the dustbin overflows.

## Main Components

- ESP32
- Ultrasonic Sensor
- Camera
- Wi-Fi/GSM
- Smart Dustbin
- Power Supply

## Working

The ultrasonic sensor measures the distance between the sensor and the waste.

The ESP32 processes the sensor reading and calculates the approximate fill level.

When the fill level reaches the predefined 80% threshold, an alert can be generated for the collection team.

The camera and AI-based object detection component are planned to provide visual confirmation of overflow or waste spillage.

## Current Prototype Status

At the 35% project stage, the prototype architecture and component selection have been completed. Hardware integration, AI model training and complete prototype testing are planned for the next phase.
