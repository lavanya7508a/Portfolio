# SQL Data Analysis

## E-Commerce Data Analytics – Level 2

This folder contains my SQL data analysis project completed as part of the E-Commerce Data Analytics Internship at Primeor Solutions.

## Project Overview

The project uses a cleaned e-commerce dataset to perform SQL-based business analysis and generate meaningful insights.

### Dataset Details

- Records: 51,271
- Unique Orders: 25,029
- Total Sales: 12,635,222.00
- Total Profit: 1,467,497.61
- Average Discount: 14.29%

## SQL Analysis Performed

- Top 10 profitable products
- Top 10 customers by sales
- Region-wise sales analysis
- Category-wise profit analysis
- Highest discount category
- Loss-making transactions
- Monthly sales trends
- Market-wise revenue and profit
- Sub-category performance
- Shipping-mode analysis
- Year-wise sales and profit
- Segment-wise performance
- Profit margin by category
- Top products by profit margin
- High-discount and loss-making records
- Region and category performance
- Average order value
- Customer purchase frequency
- Most profitable region

## Key Business Insights

- Technology generated the highest total profit.
- Central was the highest-sales region.
- APAC generated the highest market revenue.
- Copiers were the most profitable sub-category.
- Phones generated the highest sub-category sales.
- Standard Class was the most commonly used shipping mode.
- Sales increased consistently from 2011 to 2014.
- Loss-making transactions were identified for further investigation.
