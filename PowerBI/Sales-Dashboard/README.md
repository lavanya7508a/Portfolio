# Sales Dashboard

## Power BI Sales Analysis Dashboard

This project presents an interactive Power BI dashboard created to analyze sales, profit, orders, products, customers, regions, categories, and segments.

## Dashboard Pages

- Executive Overview
- Sales Analysis
- Product & Customer Insights

## Key Analysis

- Total Sales
- Total Profit
- Average Discount
- Total Orders
- Monthly Sales Trends
- Region-wise Sales
- Category and Sub-category Analysis
- Segment-wise Performance
- Top Products by Sales
- Customer Insights

## Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
- Data Analysis

## Project Objective

The objective of this project is to analyze sales data and create an interactive dashboard that provides useful business insights through KPIs, charts, filters, and visualizations.
